# Support

Start with [README.md](README.md) and [Contributing](CONTRIBUTING.md) for setup and validation. Ask usage questions in [Discussions](https://github.com/KOKUTBON/xBAKE/discussions); report reproducible bugs and propose features in [Issues](https://github.com/KOKUTBON/xBAKE/issues).

Include the project commit/version, operating system, relevant configuration, expected and observed behavior, and a minimal synthetic reproduction. Remove passwords, tokens, personal records and private documents. Search for an existing report before opening a new one.

Support is best effort. The latest default branch is the development baseline; a production support guarantee or separately maintained release must be explicitly announced. Report vulnerabilities through [SECURITY.md](SECURITY.md), and conduct concerns through [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
